# Experiment 6 — RNN, LSTM, GRU & Video Understanding

This experiment studies **RNN, LSTM, and GRU** models for sequence learning using the **UCI Human Activity Recognition (HAR)** dataset.

### Contents
- UCI HAR preprocessing and normalization
- Vanilla RNN with BPTT
- LSTM and GRU implementation
- Training/validation curves
- Accuracy, Precision, Recall, F1-score and confusion matrices
- Sequence-length comparison: 32, 64 and 128
- Video classification using **MobileNetV2 + LSTM**
- Sequence-to-sequence reversal using an encoder-decoder LSTM

### Requirements
- Python 3
- TensorFlow / Keras
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- OpenCV
- tqdm

### Run
Run the Jupyter Notebook **cell-by-cell from top to bottom**. The required datasets, models, plots and evaluation results are generated during execution.

> **Note:** Numerical performance values in the report are representative values; actual experimental results should be obtained by executing the notebook.
