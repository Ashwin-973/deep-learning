# Dependencies

- Python 3.x
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Installation

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
````

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Ashwin-973/deep-learning.git
cd deep-learning
```

2. Open Jupyter Notebook:

```bash
jupyter notebook
```

3. Navigate to:

```text
Lab 1/
```

4. Open the experiment notebook and run the cells sequentially.

## Dataset

The project uses the **Banknote Authentication Dataset** from the UCI Machine Learning Repository.

The dataset file should be placed inside the `Lab 1/` directory as:

```text
data_banknote_authentication.txt
```
