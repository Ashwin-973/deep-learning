# Dependencies

- Python 3.x
- NumPy
- Matplotlib
- TensorFlow
- Scikit-learn
- Jupyter Notebook

## Installation

```bash
pip install numpy matplotlib tensorflow scikit-learn jupyter
````

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Ashwin-973/deep-learning.git
cd deep-learning
```

2. Start Jupyter Notebook:

```bash
jupyter notebook
```

3. Navigate to:

```text
Lab 3/
```

4. Open the CNN experiment notebook and run the cells sequentially.

## Dataset

The project uses the **CIFAR-10** dataset.

The dataset is loaded directly using TensorFlow/Keras, so no separate dataset download is required.
