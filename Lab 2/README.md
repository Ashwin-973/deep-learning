## Dependencies

- Python 3.x
- NumPy
- Pandas
- Matplotlib
- Seaborn
- TensorFlow
- Scikit-learn
- SciKeras
- Jupyter Notebook

## Installation

```bash
pip install numpy pandas matplotlib seaborn tensorflow scikit-learn scikeras jupyter
````

## Running the Project

1. Clone the repository:

```bash
git clone https://github.com/Ashwin-973/deep-learning.git
cd deep-learning
```

2. Start Jupyter Notebook:

```bash
jupyter notebook
```

3. Open:

```text
Lab 2/multi_layer_perceptron.ipynb
```

4. Run the notebook cells sequentially.

```

The notebook loads **Fashion-MNIST directly through TensorFlow/Keras**, so you don't need to download the dataset separately. :contentReference[oaicite:1]{index=1}
```
